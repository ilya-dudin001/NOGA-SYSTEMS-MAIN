# NOGA Navy Map

Полнофункциональный альтернативный интерфейс Mini App. Он использует действующие
API-контракты и общую бизнес-логику фронтенда, но имеет отдельную точку входа,
дизайн-систему и дополнительные визуальные компоненты.

Основной фронтенд этим вариантом не изменяется.

## Локальный просмотр

Из корня репозитория:

```powershell
python -m http.server 5500 --bind 127.0.0.1
```

Демонстрация со встроенными данными:

```text
http://127.0.0.1:5500/redesigns/navy-map/index.html?preview=1
```

Подключение к локальному API:

```text
http://127.0.0.1:5500/redesigns/navy-map/index.html?api=http://127.0.0.1:8000
```

Без `preview=1` используются обычная Telegram-авторизация, роли, права и backend API.

## Изоляция

- `index.html` — отдельная разметка Navy Map.
- `assets/css/navy-map.css` — отдельная визуальная система.
- `assets/js/navy-map.js` — дополнительные компоненты и сводки.
- `assets/js/navy-preview.js` — локальные демонстрационные данные, включаемые только
  параметром `preview=1`.

Интеграция переключателя дизайна в основной Mini App намеренно не выполнялась:
она относится к следующему этапу после утверждения этого варианта.
