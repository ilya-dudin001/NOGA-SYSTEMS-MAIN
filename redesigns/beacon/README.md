# NOGA «Маяк»

Полнофункциональный альтернативный интерфейс Mini App с упором на читаемость
и интуитивность: графитовая тема с янтарным акцентом, контраст не ниже 4.5:1,
крупная типографика (13–27px), плоские карточки с чёткой рамкой, плавающая
панель навигации и меню создания в виде нижней шторки.

Использует действующие API-контракты и общую бизнес-логику фронтенда
(`../../assets/js/*`), но собственную разметку, дизайн-систему и дополнительные
компоненты. Основной фронтенд этим вариантом не изменяется.

Отличия от основного интерфейса:

- сводка стадий трубок на дашборде (тап по стадии открывает список с фильтром);
- баннер «города требуют внимания» — города в работе без ног или без разгруза;
- дата в шапке дашборда;
- единый акцент только для действий и активных состояний, без свечений
  и градиентных текстов;
- увеличенные контролы: кнопки от 44px, поля форм от 48px.

## Локальный просмотр

Из корня репозитория:

```powershell
python -m http.server 5500 --bind 127.0.0.1
```

Демонстрация со встроенными данными:

```text
http://127.0.0.1:5500/redesigns/beacon/index.html?preview=1
```

Подключение к локальному API:

```text
http://127.0.0.1:5500/redesigns/beacon/index.html?api=http://127.0.0.1:8000
```

Без `preview=1` используются обычная Telegram-авторизация, роли, права
и backend API. Кнопка-переключатель в шапке возвращает в основной дизайн.

## Изоляция

- `index.html` — отдельная разметка «Маяка» (те же id, что у основного
  приложения: их ждут общие JS-модули).
- `assets/css/beacon.css` — полностью автономная дизайн-система, стили
  основного приложения не подключаются.
- `assets/js/beacon.js` — дополнительные компоненты (стадии, баннер, дата).
- `assets/js/beacon-preview.js` — локальные демонстрационные данные,
  включаемые только параметром `preview=1`.
